# calculator-js

### Operations
Create the four operations of calculator:
- add
- subtract
- multiply
- divide

### Calculate
Create the function to evaluate the operation digited by the user.
In the case of more than two operands, first evaluate the expression consisting of the first two operands and save the result as the first operand for the subsequent evaluation.

### UI
Create User Interface, display and buttons of the calculator, without making all the components functional.

### Functionality
Make calculator functional:
 - Array of max two operands (String-based, converted only by in-depth math operation)
 - Operator (String-based)
 - Display update every interaction, adjusting the font size based on the length of the entered number.
